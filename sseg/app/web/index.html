O servidor guarda os processos de cada analista e prepara a caixa. Cada um entra com a chave do próprio PC e só vê os processos dele. Para entrar: "Pedir acesso", mande o código ao administrador e, quando ele liberar, "Testar conexão".

Login do SOL

Matrícula e senha do SOL, gravadas uma vez: neste PC (cofre do Windows) e no servidor, para ele entrar sozinho quando a sessão cair. A senha só passa por este campo e pelo SSH; não vai para o chat, o Git nem o log.

…

Usar pelo celular

A mesma janela no navegador do celular, com este PC fazendo o trabalho (Claude, SOL, pastas). O caminho é um túnel de saída até o servidor, e de lá ao celular pelo Tailscale: nenhuma porta se abre neste PC nem na rede do quartel, e só entra quem tiver o endereço com a chave.

Desligado.

No celular: aponte a câmera para o código, ou abra o endereço abaixo, com o Tailscale ligado. Depois, no Safari, Compartilhar → Adicionar à Tela de Início.

SOL sem teclado (opcional)

Atalho "Abrir SOL" e o script do Tampermonkey: entra com a senha que o Chrome já guarda.

Chrome para o Claude (opcional)

Deixa o Claude ler e operar uma página que já está aberta e logada no seu Chrome (SOL, por exemplo) pelo DOM, console e rede, sem print. A senha continua sendo sua. Ligado, o Claude enxerga todas as janelas do perfil do Chrome; desligue a depuração em chrome://inspect quando terminar.
